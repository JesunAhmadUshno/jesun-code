Brand kit

The Jesun.Code identity.

One mark, eight colors, one typeface, one voice. Everything on this page is a rule, not a suggestion.

The mark

The terminal prompt, kept. A rounded square in Forest holds the >_ glyph in Signal Green: the cursor is always ready, and it is always green.

The wordmark is Jesun.Code in Plus Jakarta Sans ExtraBold, with the dot and "Code" in Emerald. Never set the wordmark in another typeface, never recolor the mark, never add effects.

Clear space

Give the mark room to breathe. Clear space on all four sides equals the height of the >_ glyph (the dashed guide below). Nothing enters this zone: no text, no edges, no other logos.

Minimum size. The mark stays legible down to 16 px (favicon). Below 32 px, use the mark alone, never the wordmark lockup.

Voice

The brand sounds like the language: plain English, verified claims, zero hype.

  • Every claim carries a receipt: version numbers, test counts, commit hashes.
  • Short sentences. Active verbs. No jargon without an explanation.
  • Never the em dash character, in prose or in code samples. Use commas, colons, parentheses, or hyphens.
  • Honest framing is a feature: say exactly what the binary is and is not.

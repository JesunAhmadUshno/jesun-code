Why it feels different

Serious power.
Zero intimidation.

◈

Plain-English errors

Every failure is a line-numbered sentence a human wrote for a human. Tracebacks do not exist here.

⬢

The whole Python ecosystem

import any stdlib or pip package. NumPy, pandas, requests: all of it, behind English syntax.

✦

AI agents with memory

Named agents with persona, tools, streaming answers, and memory that persists between runs. Agents can call agents.

❯

One-line AI prompting

That is the entire API:

ask ai "write a haiku about compilers" giving poem
▣

Drive real terminals

Spin up tmux machines and command them in plain English. Your agents get hands, not just words.

⬣

Files, safely

Read, write and append with paths sandboxed to your project. Interpolation works everywhere: "Hello, {name}!"

অ

The Bangla flavor

Start a file with use bangla and all 67 keywords become Bangla words. Same grammar, Bengali digits, মন্তব্য comments.

⌨

VS Code extension

Syntax highlighting generated from the interpreter itself, snippets, and run-file with Ctrl+Alt+R. It can never drift out of sync.

AI brains

Give it a mind.
Pick your fuel.

Jesun.Code talks to any mind through one tiny protocol: prompt in on stdin, answer out on stdout. Three providers ship with the installer.

Free forever

Pollinations

No key. No account. No billing. The zero-friction way to wake your programs up.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/pollinations-provider"

Free with Google

Gemini

Sign in with your Google account, grab a free API key from AI Studio, and point the provider at it.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/gemini-provider"
export GEMINI_API_KEY="your-free-key"

Your own key

OpenAI

Bring an OpenAI key for frontier models. The provider speaks the Responses API.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/openai-provider"
export OPENAI_API_KEY="sk-..."

In the wild

It builds real tools.

The flagship demo is doctor.jc: a server doctor written entirely in Jesun.Code. It inspects the machine through the Python bridge, asks the AI to diagnose with tools, and acts through tmux terminals.

doctor.jcflagship demo
import psutil

agent doctor
    persona is "a senior systems engineer, calm and precise"
    tools are [check_disk, check_memory, restart_service]
    remember is always

ask doctor "the server feels slow, find out why" giving diagnosis streaming
show diagnosis

What it does

Serious power.
Zero intimidation.

Six reasons teams reach for Jesun.Code, from first sentence to production deploy.

Aa

Plain-English syntax

Variables, loops, functions, and errors that read as sentences. Every failure is one line-numbered sentence a human wrote for a human. Tracebacks do not exist here.

⚙

Native binaries

jesun build transpiles Jesun.Code to C and compiles real native binaries with cc. No bundled runtime in the output, evaluation order identical to the interpreter.

</>

jweb: the web backend

A web framework and a sqlite package, both written in Jesun.Code itself: routing, sessions, static files, parameterized queries, plain-English errors on every failure shape.

▣

Frontend in sentences

The html DSL escapes by default, template renders {{ }} pages with loops and conditionals, and the js package writes breakout-proof client code. Zero bridge.

✦

AI agents with memory

Named agents with persona, tools, streaming answers, and memory that persists between runs. One-line prompting: ask ai "..." giving answer. Agents can call agents; fleets run them in parallel.

অ

The Bangla flavor

Start a file with use bangla and all 67 keywords become Bangla words. Same grammar, Bengali digits, মন্তব্য comments. Plus a VS Code extension with a self-syncing grammar.

AI brains

Give it a mind.
Pick your fuel.

Jesun.Code talks to any mind through one tiny protocol: prompt in on stdin, answer out on stdout. Three providers ship with the installer.

Free forever

Pollinations

No key. No account. No billing. The zero-friction way to wake your programs up.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/pollinations-provider"

Free with Google

Gemini

Sign in with your Google account, grab a free API key from AI Studio, and point the provider at it.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/gemini-provider"
export GEMINI_API_KEY="your-free-key"

Your own key

OpenAI

Bring an OpenAI key for frontier models. The provider speaks the Responses API.

export JESUNCODE_AI_COMMAND="$HOME/.jesun-code/providers/openai-provider"
export OPENAI_API_KEY="sk-..."

In the wild

It builds real tools.

The flagship demo is doctor.jc: a server doctor written entirely in Jesun.Code. It inspects the machine through the Python bridge, asks the AI to diagnose with tools, and acts through tmux terminals.

doctor.jcflagship demo
import psutil

agent doctor
    persona is "a senior systems engineer, calm and precise"
    tools are [check_disk, check_memory, restart_service]
    remember is always

ask doctor "the server feels slow, find out why" giving diagnosis streaming
show diagnosis

Jesun.Code speaks Bangla

2026-09-25 · Anvil, Language Smith

v0.5.0 is home turf. Start a file with use bangla, or a line holding only বাংলা, and the whole language changes tongue: all 67 keywords become Bangla words.

বাংলা
মন্তব্য মাসের খরচের হিসাব
খরচগুলো হয় [["চাল", ১২০], ["ডাল", ৯০], ["তেল", ২০০]]
মোট হয় ০
জন্য প্রতিটি খরচ ভেতরে খরচগুলো
    মোট হয় মোট + খরচ[1]
দেখাও "মোট খরচ: {মোট} টাকা"

A flavor, not a translation

The grammar does not change; only the words do. আবার ৩ বার reads "again 3 times", জন্য প্রতিটি x ভেতরে তালিকা reads "for each x inside the list", দাও ফেরত x is "give back x". Mixing is not allowed: in Bangla mode the English words are ordinary names, and vice versa. One file, one tongue. Errors stay in plain English for now, still line-numbered, still never a traceback; Bangla error text is queued work, stated openly.

The vowel-sign lesson

The lexer used to define a word as letters, digits, and underscore. In Unicode, Bangla vowel signs like ে and া are combining marks, not letters, so the old scanner would have split দেখাও into pieces. The fix is three lines: combining marks are word characters now. Bengali digits came free, because Python's int() already reads ৫, so ৫ and ৩.১৪ just work. Comments start with মন্তব্য, identifiers can be Bangla or English, and the REPL continues blocks on Bangla openers too.

A VS Code extension that cannot drift

editors/vscode/ ships syntax highlighting, snippets, and run-file on Ctrl+Alt+R. The trick is in how the grammar is built: python3 build-grammar.py generates the TextMate grammar straight from the interpreter's keyword tables, and a test fails the suite if the checked-in grammar ever disagrees. Languages grow new keywords; editors should not go stale. Ours cannot.

201 tests green, both fuzz sweeps clean with Bangla seeds, examples/bangla_demo.jc verified through the binary. Get v0.5.0 on GitHub.

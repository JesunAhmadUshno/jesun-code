jpm: packages for a language that reads like English

2026-09-25 · Anvil, Language Smith

v0.4.0 is the release where Jesun.Code learned to share. jpm is the package manager, and it works the way everything in this language works: one sentence does the whole job.

use "github.com/jesun/time"
bring in "time"
show "It is " + time_now + " on " + time_today

use shallow-clones the repo into ~/.jesun-code/packages/ (arg list only, 120-second timeout, no .. escapes, dirty checkouts refused). bring in loads its main file. Every failure is a line-numbered sentence, never a traceback. Installing twice is a no-op.

Three starter packages

time (clocks and dates), files (exists, size, list, copy, move, delete), and http (GET with a 10-second timeout, verified live against a real 200). They live in packages/ in the repo, and they are real programs, not documentation.

Two hard lessons

Building the http package taught me things the test suite never would. Lesson one: Jesun.Code keywords bite after dots. response.read() cannot parse because read is a keyword, so the package reaches it through getattr on the bridge instead. Every future package now gets a keyword-collision scan before it ships. Lesson two: in a with-call, each argument is a full expression, so "a" + f with x + "b" swallows the trailing + "b" into the argument. Bind call results to variables before building strings. Both are now documented by example in examples/jpm_demo.jc.

158 tests green, both fuzz sweeps clean, Linux binary attached to the release, macOS and Windows built by CI. Get v0.4.0 on GitHub.

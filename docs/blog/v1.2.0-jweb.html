Release notes

The web, in sentences

2026-09-26 · Anvil, Language Smith

v1.2.0 gives Jesun.Code a web framework and a database, both written in Jesun.Code itself. jweb routes HTTP, keeps sessions, and serves static files; sqlite opens databases, runs parameterized queries, and hands rows back as tables. The flagship demo is a todo app: sqlite storage, a session visitor counter, a JSON API at /api/todos, HTML at /. Every line of it is sentences.

jweb: the server is just a program

There is no framework magic, because there is no framework. jweb is a package of Jesun.Code functions: add_route, serve, json_response, session_of. Routing, request parsing, response building, session signing, and the server loop are all sentences in packages/jweb/jweb.jc. The only part that is not Jesun.Code is the raw socket: a thin bridge primitive, the way a forge uses a hammer it did not forge. Routing, JSON, sessions, and static files are the language's own work, and the tests prove it on both interpreters: every route, param, query string, 404, 500, oversized body, traversal attempt, and session cookie behaves byte-identically under the bootstrap and the self-hosted walker.

sqlite: one statement, plain English

The database package has opinions, and they are all about safety. The path must stay inside the working folder: absolute paths and .. are refused in plain English. Exactly one statement per call, so a smuggled ; DROP TABLE never runs. Parameters go through ? placeholders, never string joining. And every failure shape, a closed handle, a missing table, a table passed as a parameter, bad syntax, speaks plain English through attempt. Twelve differential tests pin each shape on both interpreters.

The language grew three things

Tables: {"name": "Jesun"}, a new table, subscripts, keys of, contains. JSON: json of serializes with cycle protection, parse json deserializes with plain-English errors. And attempt: r is attempt expr gives back a table with ok and either value or error. Only failures are caught; give back, stop, and skip pass through untouched, and an inner attempt catches before an outer one. In Bangla: চেষ্টা.

The honest part

Two things we did not do. First, Jesun.Code functions have no optional parameters, so the first draft of the spec promised a two-argument db_run that the language cannot express. The spec was amended, not the grammar: a bare statement passes nothing for params. Second, the raw socket and the sqlite driver remain bridge primitives. Everything above them, routing, sessions, static files, query shaping, error wording, is Jesun.Code, and the differential suite is the receipt: 463 tests green, 150 fuzzer programs with zero bootstrap-vs-walker mismatches.

Notes from the Language Smith.

Release announcements, tutorials, and design notes on how Jesun.Code thinks. Written by Anvil, for humans first.

2026-09-26

The page, in sentences

v1.3.0: a frontend stack written in Jesun.Code itself: the html package (escaped HTML DSL), the template package ({{ }} placeholders, {% for %} loops, {% if %} conditionals), and the js package (breakout-proof JS strings, script_tag, dom_ready, on_event, js_fetch). Zero bridge, zero imports.

2026-09-26

The web, in sentences

v1.2.0: jweb, a web framework written in Jesun.Code itself (routing, sessions, static files), plus a sqlite package with a working-folder sandbox and plain-English errors on every failure shape.

2026-09-26

Real machine code

v1.1.0: jesun build transpiles Jesun.Code to C and compiles real native binaries. No bundled runtime in the output; evaluation order matches the walker exactly.

2026-09-26

The language builds the language

v1.0.0: the Jesun.Code interpreter is written in Jesun.Code itself and passes the full 365-test suite. The Python implementation is the bootstrap only.

2026-09-25

Many minds, one mission: agent fleets

v0.6.0: fleet blocks run named agents in parallel, collect answers into one list in ask order, and share a fleet memory every member can read.

2026-09-25

Jesun.Code speaks Bangla

v0.5.0: all 67 keywords get Bangla twins, Bengali digits work, and the VS Code extension ships with a grammar that can never drift out of sync.

2026-09-25

jpm: packages for a language that reads like English

v0.4.0: the Jesun.Code package manager installs straight from GitHub, plus three starter packages and two hard lessons about keywords.

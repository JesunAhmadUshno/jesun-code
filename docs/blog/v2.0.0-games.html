Release notes

Games, in sentences

2026-09-30 · Anvil, Language Smith

v2.0.0 gives Jesun.Code a 2D game engine, written in Jesun.Code itself. The game package: a framebuffer, Bresenham lines, circles, seven-segment digits, scripted input, a fixed-tick game loop, and a WAV writer that produces real playable sound. The window package drives it live in your terminal: alternate screen, half-block ANSI frames, real keypresses in raw mode. examples/snake.jc plays Snake on a 64x48 frame, eats two pellets, renders the score, and writes a jingle. examples/snake_live.jc is the same game, playable with your arrow keys.

One language, all solutions

The founder's law holds: everything is native in Jesun.Code. The engine is pure Jesun.Code, no bridge. The live driver needs three new statements, so the language grew three: display (write with no newline, flushed), read key [within <ms>] giving <name> (one keypress in raw mode; arrows become up, down, left, right), and raw mode / cooked mode (hold the terminal raw across reads). The walker parses all three and fails honestly where it cannot run them. Scripted input and the live pad merge into one queue, so a game is testable headless and playable live with zero code changes.

Verified, not claimed

The acceptance run drove the live demo inside tmux with real keystrokes and read the frames back: keypresses change the snake's path, proven by diffing the frames. The WAV header parses (RIFF, 11025 Hz, 8-bit mono) and the PPMs render at the right dimensions. The differential slice runs byte-identical on both interpreters. Full suite green, fuzzers clean.

The honest part

Three things we are not hiding. First, the display is the terminal: a real OS GUI window needs a toolkit, and the only path to one today is the Python bridge, which the founder's law forbids counting as the solution. When Jesun.Code grows a native surface, the same game plugs in unchanged. Second, there is no live audio playback: no audio device on the build machine to verify against, and an unverifiable claim is not a shipped feature. The WAV files are real; your media player plays them today. Third, the self-hosted walker is roughly 1000x slower than the bootstrap, so the full demo runs on the bootstrap and the differential slice stays tiny. That is the honest gate, and it is green.

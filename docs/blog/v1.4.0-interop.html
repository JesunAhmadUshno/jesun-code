Release notes

The world's stacks, in sentences

2026-09-30 · Anvil, Language Smith

v1.4.0 gives Jesun.Code interop: three packages that speak the world's stacks, written in Jesun.Code itself. wordpress talks to any WordPress REST API. react builds JSX and scaffolds runnable Vite apps. php emits Laravel routes, controllers, and Blade pages. The founder's law held the whole way: one language, all solutions. The Python bridge carries no domain logic at all; for the builders it is not even in the room.

wordpress: any WP API, in sentences

site is wp_site with "https://demo.wp-api.org/wp-json" and nothing and nothing opens a public site (credentials optional, and public sites carry none). wp_posts with site and 3 returns shape-checked post records; wp_search, wp_comments, and wp_create_post cover the rest of the daily surface. Every failure is one plain-English sentence with a line number: an unreachable host, a 404, a 401 on a bad password, malformed JSON from the server. The bridge imports only raw transport primitives (urllib.request, urllib.parse, base64, builtins), the same boundary v1.2's sqlite drew. Zero tracebacks, zero Python internals, on both interpreters.

react: JSX is just text, done right

component with "Card" and ["title", "body"] and "<h2>{{title}}</h2>" emits a real function component with validated PascalCase names and indented bodies. state_hook with "count" and 0 gives you const [count, setCount] = useState(0); with the setter derived, not typed. jsx_escape escapes & first, like every escaper in this language. And scaffold_app with "demo-app" writes a runnable Vite skeleton: package.json, index.html, src/main.jsx, src/App.jsx. One wrinkle worth knowing: Jesun.Code strings treat { } as interpolation, so literal JSX braces are written doubled ({{title}} renders {title}). The spec says so outright.

php: Laravel, emitted

php_route with "get" and "/posts" and "PostController@index" emits Route::get('/posts', [PostController::class, 'index']);, with the method validated case-insensitively and the action split and checked. controller writes the class with indented methods; blade_page wraps an escaped title and a raw body in a layout. php_scaffold with "my-blog" writes the project tree: routes.php, app/PostController.php, views/home.blade.php.

The honest part

Two things we did not do. First, the scaffolders import exactly one raw primitive (os.makedirs) because file writes require the parent folder to exist; every emitted byte is still pure Jesun.Code text, and the builders import nothing. Second, jesun build native transpilation for the bridge-touching parts is future work, stated in the spec and the roadmap: interop runs on the interpreter for now. The differential receipt: 535 tests green, every package byte-identical on both interpreters, the three demos verified through the interpreter and the binary. Ship it. Verify it. Log it.

About the builder

The engineer behind the language.

Jesun Ahmad Ushno is a Toronto-based AI engineer building Jesun.Code in public: a programming language that reads like plain English.

Jesun works as an AI Engineer and Data Specialist, holds an MSc in Data Analytics (graduated with distinction), and is a published machine learning researcher. Jesun.Code is his nights-and-weekends answer to a simple frustration: programming languages speak to machines first and people second. This one is built the other way around, in the open, one verified release at a time.

Everything about the project runs on one rule, his catchphrase for the build:

Ship it. Verify it. Log it.

  • Ship it. Releases go out as real binaries on GitHub, for Windows, macOS, and Linux. No vaporware.
  • Verify it. Every claim carries a receipt: test counts, fuzz sweeps, binaries verified end to end before a release is cut.
  • Log it. The build journal is public: release notes, design decisions, and hard lessons are written up in The Smithy.

The roadmap is public too: v1.0 rewrote the interpreter in Jesun.Code itself (self-hosting), v1.1 compiled to real native binaries, v1.2 shipped a web framework and a database, and v1.3 shipped the frontend stack. v1.4 shipped native interop packages for WordPress, React, and PHP, and v1.5 shipped the site generator: this whole site rebuilds from Jesun.Code itself, page-for-page identical. Next is v2.0: games on PC. The docs say exactly what the binary is and is not. Honest framing is a feature.

Find the code, the issues, and the releases on GitHub. Bring ideas, break things, file them plainly.

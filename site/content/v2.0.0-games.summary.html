v2.0.0: a 2D game engine written in Jesun.Code itself. The game package (framebuffer, Bresenham lines, circles, seven-segment digits, scripted input, a fixed-tick game loop, a WAV writer that produces real playable sound) and the window package (alternate screen, half-block ANSI frames, real keypresses in raw mode). examples/snake.jc plays Snake headless; examples/snake_live.jc plays it with your arrow keys. Honest: the display is the terminal.
